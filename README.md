# My Cervical Recovery Journey

Open `index.html` in a browser to view the website.

The site is a responsive, single-page personal story covering:
- 2014: start of IT career
- September–October 2016: symptoms begin
- 2016–2017: worst period
- Physiotherapy/medical treatment and recovery
- 2020: physiotherapy again
- Career break, exercise, walking, rest and reduced screen use
- Cricket umpiring and return to professional life
- 2024–2026: developer/MNC life
- Current routine and lessons

The illustrations are built into the page, so the site works without an image folder.
You can later replace the hero illustration with your own photo or professionally created medical/recovery illustrations.
